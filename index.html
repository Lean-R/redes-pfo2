PFO2 - Gestor de tareas

Programación sobre redes

Qué es

API hecha con Flask que guarda usuarios y tareas en SQLite, más un cliente de consola para usarla. Las contraseñas se guardan hasheadas y cada tarea queda asociada a su usuario.

El código completo está en el repositorio: github.com/Lean-R/redes-pfo2
